DBZ BT2 Accessibility Guide - Playtest 2026.09.05-r4
Windows x64

GETTING STARTED

1. Extract the entire ZIP to a folder. Keep the worker folder beside
   DBZ BT2 Guide.exe. Do not run the application from inside the ZIP.
2. Use your own PCSX2 installation, PS2 BIOS dump, and USA Dragon Ball Z -
   Budokai Tenkaichi 2 game dump (SLUS-21441, CRC FE961D28). This build was
   tested with PCSX2 2.6.3. Other regions are not supported by this build.
   Configure your controller and memory card in PCSX2 normally.
3. Open DBZ BT2 Guide.exe. Its first-run Settings window automatically searches
   running instances, installed and portable PCSX2 copies, PCSX2 game libraries,
   common game folders, and local drives. Choose a result only when several are
   found, then Save. Browse remains available for an unusual folder.
4. Choose Open game. While PCSX2 is closed, the guide enables PINE in that
   installation's own configuration and retains its configured port. It creates
   a settings backup beside PCSX2.ini first. Portable marker files and the
   -portable launch mode are supported. No Python installation or terminal is
   needed. Windows 10/11 x64 with .NET Framework 4.8 is required.
5. Choose Open game, then Start guide. Load or begin your own Dragon
   Adventure game. Use Alt+Tab to return to the game for guidance.
   You can also launch the game directly in PCSX2 and then start the guide;
   the Settings paths are only needed for the Open game button.

SCREEN READERS AND CONTROLS

The interface uses standard Windows controls. Tab and Shift+Tab move focus;
Enter or Space activates buttons. NVDA is used by default when running.
Windows SAPI speech is the automatic backup. NVDA itself is not bundled.
The Speak guide messages checkbox can turn off the guide's speech.

Start guide starts the companion. Stop guide silences and stops it while
leaving the game open. Closing the guide also stops its worker. The Latest
message and Message history fields keep messages available for review.
Guidance pauses while another window has focus so you can use your reader.

With the game focused:
  R: repeat the destination.
  N / B: next / previous local or explicitly selected destination.
  T: request optional teleport; follow its spoken instructions and pause
     emulation in PCSX2 before the requested move can occur.
  L1 on a detected standard DualSense: same teleport request as T.

Ordinary overworld guidance selects an objective from the live minimap and
tracks the player arrow there. Stereo direction and pitch provide movement
cues; spoken messages explain the destination and approach. Keep the game
window visible and its minimap unobstructed. Start in windowed mode with
the original HUD; texture replacements or HUD changes are untested.

MAPS AND PROGRESS

The atlas starts empty and learns maps as you visit them. Lighting changes
alone do not create maps. Newly discovered maps receive descriptive labels
and numbers. These are descriptions, not guaranteed official map names.
While stopped, select a Discovered map, enter a Map name, and choose Save
map name to give it your preferred name. Some maps may remain temporary
until their identity can be confirmed.

This package contains no game, BIOS, emulator, saves, memory cards,
savestates, recorded game images, RAM dumps, or prefilled player atlas.
The guide uses the memory card you configured in PCSX2. It does not swap
memory cards or supply unlocked progress. The optional teleport changes
live player coordinates only when its pause and validation checks pass.

Settings, logs, and newly learned maps are stored under:
  %LOCALAPPDATA%\DBZ BT2 Guide
They remain separate from this extracted release and from PCSX2's saves.

PLAYTEST NOTES AND TROUBLESHOOTING

This is a playtest of Dragon Adventure navigation and of menu reading, not
complete menu, battle, or whole-game accessibility. Unfamiliar maps still
need wider live testing.

Menus that speak: the title screen, the main menu, Options, the Select
Scenario list in Dragon Adventure, and the Game Level chooser reached after
picking a story event. F12 reads the game's own text for the current screen.
Screens the guide recognises but has not mapped are named and then stay
quiet; screens it does not recognise say so rather than guessing. Choosing
which individual story event to play is still done blind, and story cutscene
subtitles are not read yet.

The scenario names are pictures rather than words in the game's memory, so
the guide reads them from a list written by hand, and that list is right for
the scenarios unlocked when it was written. Unlock another and the guide
will not know its name; rather than say nothing it says "Scenario 3, name
not known." Please report it when you hear that, because it also means the
names it already knows may have shifted.

The event name F12 reads on the Game Level screen is wrong on every event
but the first, and known to be: it reads the first entry of the game's list
of event names rather than the one you chose, so it says "Mysterious Alien
Warrior" whatever you are playing. Ignore it for now. The instruction line
beside it is correct.

This release omits the api-ms-win-*.dll compatibility stubs that release
2026.09.05-r4 carried. They forward to the Universal C Runtime, which is
part of Windows 10 and 11, and Windows 10/11 x64 is what this guide
requires. Nothing was lost that a supported system needs. An ambiguous objective may remain unconfirmed; the guide should
say that rather than inventing a route. This build has not been tested on
a separate clean Windows computer.

If waiting for a connection: close PCSX2 normally, confirm the right copy is
selected in Guide Settings, then choose Open game so the guide can enable and
use that copy's PINE port. If guidance is silent: return focus
to the game, check Speak guide messages, and read Message history. If the
runtime is missing: extract the complete ZIP again with its worker folder.
If the worker stops unexpectedly, the UI keeps the error available; use
Start guide to retry. Runtime errors are retried without closing the guide.
An unrecoverable startup error is written to logs\last-worker-error.txt.
Save the relevant log when reporting a problem.

For feedback, include this release version, PCSX2 version, map or chapter,
what you did, what you expected, and the relevant guide log. Review logs
before sharing them; they can contain your chosen map names and local paths.
Do not send game dumps, BIOS files, or saves with bug reports.

The source folder contains this guide's runtime/UI source for inspection.
Third-party notices and versions are in licenses and THIRD-PARTY.txt.
